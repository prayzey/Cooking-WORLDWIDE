## System

- Light canvas with deep ink-blue text, cobalt action color, and electric blue highlights.
- Display type uses a distinctive serif for authority; body copy stays clean and highly readable.
- Visual language uses thin drafting lines and annotation marks sparingly, never as a decorative grid overlay.
- Motion is limited to a single staggered reveal and a calm signal pulse on the workflow diagram.
